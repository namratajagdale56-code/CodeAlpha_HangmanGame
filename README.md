# CodeAlpha Hangman Game

## Project Overview
This is a simple text-based Hangman Game developed using Python as part of the CodeAlpha Python Programming Internship.

The player has to guess a randomly selected word one letter at a time. The game allows a maximum of 6 incorrect guesses.

## Features
- Random word selection from 5 predefined words
- Letter-by-letter guessing
- Maximum of 6 incorrect guesses
- Input validation
- Detection of repeated guesses
- Win and game-over messages

## Technologies Used
- Python
- random module
- Loops and conditional statements
- Strings and lists
- Functions

## How to Run
1. Install Python 3.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:


python hangman.py
